# Smart Transformer Health Monitoring System

MATLAB R2026a academic project for monitoring transformer voltage, current, and load and indicating abnormal operating conditions using basic threshold-based fault logic.

## Project scope
- Monitor transformer voltage, current, and loading conditions.
- Introduce simulated abnormal operating conditions.
- Detect abnormal voltage, load warning, and overload conditions.
- Display four monitoring graphs.

## Files
- `smart_transformer_monitor.m` — main MATLAB script.
- `figures/transformer_monitoring_output.png` — example output graph.

## How to run
Open MATLAB R2026a, set this folder as the Current Folder, open `smart_transformer_monitor.m`, and click Run.

## Simulated events
- 15–25 s: overload
- 30–38 s: abnormal voltage
- 45–53 s: severe overload

No external hardware is required.
